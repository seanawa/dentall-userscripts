Dentall 腳本 安裝清單

泓泰牙醫診所公用電腦用。照順序打勾，七步完成。進度只存在這台電腦的瀏覽器裡。

0 / 7

1. 安裝 Tampermonkey 擴充功能

用 Chrome 打開下面連結，按「加到 Chrome」→「新增擴充功能」。

開啟 Chrome 線上應用程式商店

裝好後，Chrome 右上角拼圖圖示裡會多一個黑底方塊的 Tampermonkey。建議點拼圖旁的「釘選」把它固定在工具列。

2. 開啟「允許使用者指令碼」

新版 Chrome 沒開這個，腳本就算裝了也不會執行。這個設定頁無法用點的，請複製後貼到網址列：

chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo
  1. 在 Chrome 網址列貼上，按 Enter，會打開 Tampermonkey 的詳細資料頁。
  2. 往下找到「允許使用者指令碼」(Allow User Scripts)，把右邊開關點成藍色。
舊版 Chrome 若找不到這個選項，改到 chrome://extensions 右上角把「開發人員模式」打開。

3. 安裝腳本

點下面按鈕，會跳出 Tampermonkey 的安裝畫面，按「安裝」。

安裝「Dentall 就診列表 記住排序」 安裝「Dentall 就診列表 新掛號提醒」 安裝「Dentall 健保批價單 加印下次預約」 安裝「Dentall 健保收據 附印醫療確認單」 安裝「Dentall 自動登入」

五支都裝；每一支都會各自跳出安裝畫面，各按一次「安裝」。

如果點了只看到一整頁文字，沒有安裝畫面，代表步驟 1 或 2 沒完成。回去補做後再點一次。

4. 完全關閉 Chrome，再重新打開

讓剛才的設定和腳本確實生效。

  1. 關掉所有 Chrome 視窗。Windows 請再看一下右下角工作列的隱藏圖示，若還有 Chrome 圖示，右鍵 →「結束」。Mac 請按 Cmd+Q。
  2. 重新打開 Chrome。

5. 登入 Dentall 並確認腳本有在跑

開啟 Dentall HIS

登入後，在 Dentall 頁面點工具列的 Tampermonkey 圖示，應該看到：

  1. 圖示右下角有數字 5（等於已安裝的腳本數）。
  2. 清單裡有「Dentall 就診列表 記住排序」「Dentall 就診列表 新掛號提醒」「Dentall 健保批價單 加印下次預約」「Dentall 健保收據 附印醫療確認單」「Dentall 自動登入」，開關都是綠色。每一支只能出現一次，重複的要刪掉。
  3. 彈窗最上方沒有藍色橫幅寫「請啟用『允許使用者腳本』」。有的話回步驟 2。

6. 實際測試一次

  1. 在「就診列表」點一位已經排好下次預約的病患，進入處置單（網址有 #/pd/）。
  2. 按列印圖示 →「健保批價單」。
成功：列印預覽的收據底部（註記 3 下方）出現置中粗體的「下次預約：115/10/15（四）14:30」這類文字，而且預覽第 2 頁是 A5 的「醫療確認單」，姓名、就醫日期、院所名稱/代號已經填好。可以直接取消不印。
失敗：底部沒有那行字。先按 F5 重新整理 Dentall 頁面再試一次；病患若沒有未來預約本來就不會印，請換一位有預約的病患測。仍不行就回到步驟 5 檢查。

7. 設定開機自動登入

目標：Windows 開機後 Chrome 自己打開、還原就診列表分頁，Dentall 若已登出會自動登入，不用按任何東西。

  1. 設定帳號密碼：在 Dentall 頁面點 Tampermonkey 圖示 →「Dentall 自動登入」→「🔑 設定帳號密碼」，填好按「儲存」。帳號密碼只存在這台電腦。
  2. 開好分頁：就診列表開在一個分頁，在分頁上按右鍵 →「釘選」；其他操作開另一個分頁。下班直接關機，不要關掉這兩個分頁。
    https://his.dentall.io/htdc/#/registration
  3. Chrome 開啟時還原分頁：複製下面網址貼到網址列，選「繼續瀏覽上次開啟的頁面」。
    chrome://settings/onStartup
  4. 開機自動打開 Chrome（Windows）：開始按鈕按右鍵 →「執行」，貼上下面這行按「確定」，會打開「啟動」資料夾。
    shell:startup
    在資料夾空白處按右鍵 →「新增」→「捷徑」，位置貼上下面這行 →「下一步」→ 名稱打「Chrome」→「完成」。
    "C:\Program Files\Google\Chrome\Application\chrome.exe"
    出現「找不到」的話，把 Program Files 換成 Program Files (x86) 再試。
  5. Dentall 分頁不被卸載（Windows，需要系統管理員權限）：打開下面的 GitHub 頁面，按右上角「Download raw file」下載，雙擊下載的檔案 → 權限視窗按「是」→ 匯入確認按「是」。 下載 chrome-policy-dentall.reg
    完全關閉 Chrome 再打開，把下面網址貼到網址列，確認 TabDiscardingExceptions 的狀態是「正常」。
    chrome://policy
    旁邊的 RestoreOnStartup 顯示被封鎖或忽略是正常的（沒加入網域的電腦 Chrome 不吃這條），上面第 3 點已經手動設好。
測試：兩個分頁開著，直接重新開機，開機後什麼都不要按。Chrome 自己打開、兩個分頁都還原、Dentall 已登入、釘選的分頁停在就診列表，就成功了。
沒有自動登入：登入頁下方會有一條橘色提示說明原因；也可以點 Tampermonkey 圖示 →「Dentall 自動登入」→「📋 最近紀錄」查看。登入失敗一次就會暫停，確認帳號密碼後從同一個選單恢復。
Windows 開機若要輸入密碼，要先有人登入 Windows，Chrome 才會打開。

常見問題

點安裝連結只看到文字Tampermonkey 沒裝，或步驟 2 的開關沒開。
Tampermonkey 圖示沒有數字 5不在 Dentall 頁面、腳本開關被關掉、或步驟 2 沒開。
有藍色橫幅「請啟用允許使用者腳本」步驟 2 沒開。開完要重新整理 Dentall 頁面。
腳本以後怎麼更新不用動。Tampermonkey 每天會自動檢查 GitHub 上的新版。
