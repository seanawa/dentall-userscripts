Dentall 報表瀏覽 安裝清單

泓泰牙醫診所公用電腦用。照順序打勾，六步完成。進度只存在這台電腦的瀏覽器裡。

1. 安裝 Tampermonkey 擴充功能

用 Chrome 打開下面連結，按「加到 Chrome」→「新增擴充功能」。

開啟 Chrome 線上應用程式商店

裝好後，Chrome 右上角拼圖圖示裡會多一個黑底方塊的 Tampermonkey。建議點拼圖旁的「釘選」把它固定在工具列。

2. 開啟「允許使用者指令碼」

新版 Chrome 沒開這個，腳本就算裝了也不會執行。這個設定頁無法用點的，請複製後貼到網址列：

chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo
  1. 在 Chrome 網址列貼上，按 Enter，會打開 Tampermonkey 的詳細資料頁。
  2. 往下找到「允許使用者指令碼」(Allow User Scripts)，把右邊開關點成藍色。
舊版 Chrome 若找不到這個選項，改到 chrome://extensions 右上角把「開發人員模式」打開。

3. 安裝腳本

點下面按鈕，會跳出 Tampermonkey 的安裝畫面，按「安裝」。

安裝「Dentall 治療項目統計 線上瀏覽」
如果點了只看到一整頁文字，沒有安裝畫面，代表步驟 1 或 2 沒完成。回去補做後再點一次。

4. 完全關閉 Chrome，再重新打開

讓剛才的設定和腳本確實生效。

  1. 關掉所有 Chrome 視窗。Windows 請再看一下右下角工作列的隱藏圖示，若還有 Chrome 圖示，右鍵 →「結束」。Mac 請按 Cmd+Q。
  2. 重新打開 Chrome。

5. 登入 Dentall 並確認腳本有在跑

開啟 Dentall HIS

登入後，在 Dentall 頁面點工具列的 Tampermonkey 圖示，應該看到：

  1. 圖示右下角有數字 1。
  2. 清單裡有「Dentall 治療項目統計 線上瀏覽」，開關是綠色。
  3. 彈窗最上方沒有藍色橫幅寫「請啟用『允許使用者腳本』」。有的話回步驟 2。

6. 實際測試一次

  1. Dentall 上方選單「分析報表」→「治療項目統計」。
  2. 日期選昨天，處置項目選「全部代碼」，按「匯出 EXCEL」。
  3. 右側出現新的一筆，等「製作中」變成「下載報表」後點它。
成功：畫面直接跳出統計表，有「統計（項目 × 醫師）」「統計（醫師 × 項目）」「明細」三個分頁，沒有下載任何檔案。
失敗：還是下載了 Excel。先按 F5 重新整理 Dentall 頁面再試一次，仍不行就回到步驟 5 檢查。

常見問題

點安裝連結只看到文字Tampermonkey 沒裝，或步驟 2 的開關沒開。
Tampermonkey 圖示沒有數字 1不在 Dentall 頁面、腳本開關被關掉、或步驟 2 沒開。
有藍色橫幅「請啟用允許使用者腳本」步驟 2 沒開。開完要重新整理 Dentall 頁面。
想要 Excel 檔報表視窗右上角有「下載 Excel」按鈕，功能和原本一樣。
腳本以後怎麼更新不用動。Tampermonkey 每天會自動檢查 GitHub 上的新版。
